# 2026-10-29 墨刀原型同步记录

本轮按用户确认的当前墨刀版本同步到本地，详见 [项目 README](../README.md)。

## 实现范围

统一登录、两端顶部返回和退出、完整 Study Seat 英文名、移除选座页重复圆形箭头，以及管理端规则/开放时段/关闭与重新开放/记录日志 MVP。学生预约逻辑保留，同一次打开内退出重登保留数据；刷新恢复初始场景。管理端与学生端业务数据独立。

采用与墨刀相同的两份独立交互内容及统一宿主。`prototype/` 中保留可维护页面、适配器和桥接脚本；`scripts/build-prototype.py` 生成 `deploy/` 静态文件并更新资源内容版本。正式运行不需要生成步骤。历史页面书签返回统一登录入口。

原 localStorage 数据不读写、不删除；当前会话使用内存。这个变化用于与墨刀演示行为一致，不构成旧数据迁移。早期持久化测试和截图属于历史版本；不将旧测试记录冒充本轮验收。
