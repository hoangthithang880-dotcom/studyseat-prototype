# Study Seat 知行有座 · 与墨刀一致的交互原型

本地正式版本位于 `deploy/`，已同步 2026-10-29 确认的墨刀统一入口、学生端和管理端 MVP。纯静态、无后端、无运行时构建步骤。

## 启动

在本目录执行：

```sh
python3 scripts/preview.py --directory .
```

打开 [本地统一入口](http://127.0.0.1:8765/deploy/)。在上一级工作区启动时，打开 [工作区入口](http://127.0.0.1:8765/studyseat-prototype-master/deploy/)。预览服务禁止缓存。建议 Chrome；请通过 HTTP 访问。

## 与墨刀保持一致的行为

- 完整显示 **Study Seat**；375×812 的原型内容与墨刀一致，桌面浏览器增加居中外框。
- 所有业务视图顶部有“退出登录”，子视图有“返回”。选座标题左侧的重复圆形返回箭头已删除。
- 学生保留选座、预约、防重复提交、签到、暂离、返回、取消、结束及个人预约隔离；成功回执关闭后进入“我的预约”。
- 管理端支持规则版本保存、开放时段、关闭座位或整间、影响预览、取消待签到记录、重新开放、关联预约、通知内容预览和只读操作日志。
- 返回保留选座草稿；管理预览可返回修改，关联预约可返回关闭详情。管理端未保存修改在离开或退出时提示。
- **学生与管理端业务数据独立。** 管理端关闭资源不改变学生端模拟预约，通知仅为管理端内容预览。
- **同一次打开中退出、重新登录会保留数据；刷新整个页面、重新打开会恢复初始场景。** 当前存储在内存，不读写旧版本 localStorage 预约数据，也不会删除它们。不同标签页之间不共享业务数据。
- 初始演示时钟为北京时间 **2026-10-28 13:50**，学生端随真实秒数推进。初始草稿为 A101 / A08 / 14:00–16:00。长时间演示后可用“工具”调整时间或刷新重新开始。管理端使用同日固定示例场景。
- 原本的学生单次最长 4 小时、提前 7 天、签到前 10 分钟至后 15 分钟、暂离上限 30 分钟均为团队演示参数。管理规则的新版本仅作用于管理端场景，既有管理预约保留创建时快照。

历史 `home.html`、`room.html`、`rules.html` 等书签统一返回正式登录入口，不能进入已停用的独立页面。

## 演示建议

1. 学生 A 登录 → 立即选座 → 确认选座 → 返回检查草稿 → 提交预约 → 我的预约。
2. 同一预约可演示签到、暂离、返回与结束；顶部“工具”用于演示时钟。
3. 退出 → 学生 A 重登查看原预约 → 学生 B 登录确认账号隔离。
4. 管理员登录 → 暂离时长改为 45 → 保存为 V2 → 退出重登检查版本保留。
5. 资源管理 → 关闭 A101 → 预览影响 → 确认 → 关联预约 → 返回关闭详情 → 重新开放。取消的预约不会自动恢复。
6. 切回学生端，说明其独立数据未受管理操作影响。刷新后恢复初始场景。

## 测试与维护

```sh
node --test tests/*.test.cjs
# 修改 prototype/、域模型、原型样式或导航后，重新生成静态发布文件：
python3 scripts/build-prototype.py
# 等价兼容命令：
node scripts/version-assets.cjs
```

浏览器回归需先启动本地服务，并安装锁定的开发依赖（`pnpm install --frozen-lockfile`）：

```sh
STUDYSEAT_BASE_URL=http://127.0.0.1:8765/deploy/ node tests/browser.cjs
```

`STUDYSEAT_NODE_MODULES` 可指定已有 Playwright 模块位置，`STUDYSEAT_CHROME` 可指定已安装的 Chrome。浏览器验收脚本也导出相同检查函数，可由 Codex 的浏览器工具运行。
